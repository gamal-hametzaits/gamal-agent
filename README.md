# 🐪 הגמל (Gamal) — סוכן אישי לאנדרויד

סוכן אישי שרץ **כולו במכשיר**. ממשק צ'אט בעברית (RTL), זיכרון מקומי, למידה מהתראות (באישור מפורש בלבד), ולולאת משוב שמעצבת את ההעדפות של הסוכן. חלק ממותג **הגמל המצייץ**.

## מה יש ב-v0 (ועובד)

- **ממשק צ'אט** — שיחה עם הגמל, סוכן מקומי שעונה בעברית. עיצוב כהה עם הדגשים אדומים, RTL מלא.
- **זיכרון על המכשיר** — כל השיחות, הדירוגים וההעדפות נשמרים במסד נתונים מקומי (SQLite מקומי). שום דבר לא יוצא מהמכשיר.
- **קליטת התראות** — שירות Notification Listener ששומר כותרות ותוכן של התראות נכנסות לארכיון מקומי מתגלגל (7 ימים). פועל **רק אחרי** שהמשתמש מאשר "גישה להתראות" בהגדרות המערכת, ויש מתג כיבוי/הפעלה בתוך האפליקציה. הסוכן יודע לסכם: "מה קיבלתי היום?".
- **לולאת משוב** — כל תשובה של הסוכן ניתנת לדירוג 👍/👎. הדירוג מעדכן פרופיל העדפות מקומי (אורך תשובות מועדף, נושאים קרובים ללב), והתשובות הבאות מסתגלות בהתאם.

## מה אין ב-v0 (בכוונה, ובשקיפות)

- **אין האזנה למיקרופון.** אנדרויד חוסמת הקלטת רקע מתמשכת מסיבות פרטיות, וגם אם לא — זה לא חלק מהעיצוב. הגמל לומד רק ממה שאתה נותן לו במפורש: צ'אט, דירוגים, והתראות שאישרת לו לראות.
- **אין מודל שפה מלא.** התשובות ב-v0 מבוססות כללים שקופים שרצים מקומית. זה הבסיס הכנה — לא "AI" מדומה.
- **אין סנכרון ענן.** הכול מקומי. גיבוי/סנכרון הוא החלטה עתידית שלך.

## מפת דרכים — לקראת למידת חיזוקים אמיתית (RL)

לולאת הדירוגים של v0 היא בדיוק מבנה הנתונים ש-RL צריך: `(מצב, פעולה, תגמול)` — הקשר השיחה, תשובת הסוכן, והדירוג שלך. השלבים הבאים:

1. **v0.1 — ייצוא נתוני משוב** — ייצוא מקומי של רשומות `(context, reply, rating)` בפורמט פתוח, כך שאפשר יהיה לאמן/לכייל מודל בחוץ כשתרצה.
2. **v0.2 — מודל תגמול מקומי** — במקום כללים קבועים, מנבא קטן על המכשיר שמעריך "כמה תאהב תשובה כזו" לפי היסטוריית הדירוגים, ומשפיע על בחירת התשובה.
3. **v0.3 — מודל שפה קטן על המכשיר** — הרצת LLM קטן (למשל משפחת Gemma/Llama הקומפקטיות) מקומית, עם כיוול (LoRA/DPO) מהמשוב שלך — עדיין בלי שדבר יוצא מהמכשיר.
4. **v1 — RL מלא מהמשוב שלך** — עדכון מדיניות מתמשך (DPO/PPO-lite) על בסיס הדירוגים, עם שמירת גרסאות מודל ואפשרות rollback.

כל שלב נשאר נאמן לאותו עקרון: **הנתונים שלך נשארים אצלך, והלמידה שקופה וברת-כיבוי.**

## בנייה מקומית

דרישות: JDK 11+, Android SDK (platform 33, build-tools 33.0.2).

```bash
# צור local.properties בשורש הפרויקט:
# sdk.dir=/path/to/Android/Sdk
./gradlew assembleDebug        # APK חתום דיבאג: app/build/outputs/apk/debug/app-debug.apk
```

לחתימת release משלך:

```bash
keytool -genkeypair -keystore gamal.keystore -alias gamal -keyalg RSA -keysize 2048 -validity 10950
# הוסף ל-local.properties (לא לעולם ב-git):
# gamal.storeFile=/abs/path/gamal.keystore
# gamal.storePassword=...
# gamal.keyAlias=gamal
# gamal.keyPassword=...
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
```

התקנה במכשיר: העתק את ה-APK ופתח אותו (נדרש "התקנה ממקורות לא מוכרים"), או `adb install app-release.apk`.

## הפעלת קליטת ההתראות

1. התקן את האפליקציה ופתח **הגדרות** (גלגל השיניים).
2. לחץ **פתח הגדרות גישה להתראות** ואשר את הגמל ברשימה.
3. ודא שהמתג "למידה מהתראות" דולק. מרגע זה ההתראות נשמרות מקומית ל-7 ימים, ואפשר לשאול את הגמל "מה קיבלתי היום?".
